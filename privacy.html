Privacy policy

Baltisimo is a personal assistant used only by its owner. When the owner connects their Google account, Baltisimo reads and changes Gmail, Calendar, Drive, Docs and Sheets data only to carry out the owner's own requests.

Google user data is stored only on the owner's computer, is not sold, and is not shared with anyone. Requests the owner makes are processed by Google's Gemini API to generate responses. Baltisimo's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
